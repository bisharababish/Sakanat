Project folder: C:\Users\2026\Desktop\sakanat
Expo SDK 57 — use Expo Go on your phone.

------------------------------------------------
1) ONE-TIME SETUP
------------------------------------------------

cd C:\Users\2026\Desktop\sakanat

# Install dependencies
npm install

# Env file (copy if you don't have .env yet)
# copy .env.example .env
# Then fill:
#   EXPO_PUBLIC_SUPABASE_URL=...
#   EXPO_PUBLIC_SUPABASE_ANON_KEY=...

------------------------------------------------
2) START THE APP (every day)
------------------------------------------------

cd C:\Users\2026\Desktop\sakanat
npx expo start

# Same thing via npm script:
npm start

# Then:
# - Scan the QR code with Expo Go (Android) / Camera (iOS)
# - Or press a = Android emulator
# - Or press w = web browser

# Clear cache if something looks stuck:
npx expo start -c

# Tunnel (if phone and PC are not on the same Wi‑Fi):
npx expo start --tunnel

------------------------------------------------
3) PLATFORM SHORTCUTS (optional)
------------------------------------------------

npm run android
npm run ios
npm run web

------------------------------------------------
4) SUPABASE SQL (SQL Editor — run in this order)
------------------------------------------------

Open each file in the repo, copy all, paste into Supabase → SQL Editor → Run:

1. supabase/analytics-rate-limits.sql
2. supabase/push-triggers.sql
3. supabase/product-ops.sql

Optional check after product-ops.sql:
  select public.run_booking_ops();
